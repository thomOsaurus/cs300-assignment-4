PROJECT DESCRIPTION:

This React application allows the user to manage a personal reading list.

The user can add books through a form with input validation, search and filter their collection, and remove books from the list.
The application uses reusable React components, props, callbacks, and state management to provide an interactive and responsive experience .

HOW TO RUN:
1. Clone the GitHub repository
2. Open the project folder in VS Code
3. Open a terminal and run:

```bash
npm ci
npm run dev
npm test
```
